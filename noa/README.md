# נועה 💛

אפליקציה פרטית, רק שלך, לכל מה שחשוב לדעת עליה ולעשות בשבילה: מה היא אוהבת ומה פחות, המידות שלה, האנשים שחשובים לה,
מקומות, תאריכים חשובים, רעיונות למתנות, תוכניות ודייטים, זיכרונות ושאלות לשיחה. השם שלה הוא גם השם של האפליקציה —
ואפשר לשנות אותו בהגדרות.

## איך פותחים

- **בטלפון (מומלץ):** פותחים את הכתובת של האפליקציה בכרום, ואז תפריט ⋮ ← "הוספה למסך הבית" (או "התקנת אפליקציה").
  מכאן היא נפתחת כמו כל אפליקציה, עובדת גם בלי אינטרנט, ונראית הכי טוב במראה הבהיר.
- **במחשב:** פותחים את `noa/index.html` בדפדפן (או את הכתובת באתר). אין צורך בהתקנה.

בפתיחה הראשונה יש שלושה צעדים קטנים (השם שלה, מתי התחלתם, יום ההולדת שלה) — כל אחד אפשר לדלג. רוצה לראות קודם איך זה
נראה? "להציץ קודם בדוגמה" טוען נתוני דוגמה בדויים, ולחיצה אחת מנקה אותם.

## פרטיות

- **הכול נשמר רק במכשיר שלך**: הנתונים בדפדפן (localStorage), התמונות באחסון שלו (IndexedDB). אין חשבון, אין שרת,
  אין מעקב ואין שום קריאה לרשת. קישורים למפות או לאתרים נפתחים רק כשאתה לוחץ עליהם.
- **נעילה:** קוד של 4–6 ספרות (נשמרת רק "חותמת" PBKDF2 של הקוד, לא הקוד עצמו), טביעת אצבע / זיהוי פנים אם הטלפון תומך,
  נעילה אוטומטית אחרי זמן שתבחר, ו"הסתרת תוכן" — כשעוברים לאפליקציה אחרת המסך מטושטש, גם בתצוגת האפליקציות האחרונות.
  הנעילה מסתירה את המסך; היא לא מצפינה את הנתונים.
- **גיבוי:** בהגדרות ← "גיבוי ושחזור" מורידים קובץ JSON (אפשר "כולל תמונות"), ומשחזרים ממנו בכל מכשיר. האפליקציה
  מזכירה לגבות כל 30 יום. כל שמירה נכתבת קודם לעותק זמני, והשמירה הקודמת נשמרת תמיד — אפשר לשחזר אותה מההגדרות.

## תזכורות

הדרך הבטוחה ביותר: הגדרות ← תזכורות ← **"הורדת קובץ היומן (.ics)"**, ופותחים את הקובץ ביומן Google או Samsung — כל
התאריכים והתזכורות נכנסים ליומן, והטלפון מזכיר גם כשהאפליקציה סגורה. בנוסף, כשפותחים את האפליקציה, תזכורות של היום
מופיעות בבית (ואם אישרת התראות — גם כהתראה).

## למפתחים

- קוד: `noa/src/*.js` (JavaScript רגיל, בלי תלויות), עיצוב: `noa/src/ui/*.css`. המבנה, ה־API לכל מסך והרכיבים
  המשותפים מתוארים ב־[`API.md`](API.md); כל הרכיבים במצביהם נראים בעמוד `#gallery`.
- בנייה: `node noa/scripts/build.mjs` → `noa/index.html` ו־`noa/dist/index.html` (קובץ HTML אחד עם הגופן, ה־CSS
  וה־JS בפנים) + manifest, service worker ואייקונים. בנייה פרטית: `NOA_OUT=/path/file.html node noa/scripts/build.mjs`.
- בדיקות: `cd noa && npm test` (node --test לכל `src/*.test.js`), ניגודיות צבעים: `node noa/scripts/palette-check.mjs`
  (11 פלטות × בהיר/כהה, כל טקסט ≥ 4.5:1 על הזכוכית).
- כל מפתחות האחסון מתחילים ב־`noa-` (האפליקציה "אופק" יושבת באותו אתר עם `ofek-`; נועה לעולם לא נוגעת בהם).
